# Central Financeira - Protótipo

Protótipo inicial da aplicação de controle financeiro descrita no prompt.

## Como executar

```bash
npm install
npm run dev
```

Abra o endereço informado pelo Vite.

## Observação

Este protótipo é uma demonstração visual e funcional em frontend. A integração real com Santander/API e autenticação persistente ainda não está conectada a serviços externos.
