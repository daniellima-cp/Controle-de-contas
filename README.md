# Central Financeira - Versão 2

Protótipo atualizado da Central Financeira.

Correções incluídas: filtros funcionais na Visão geral, cards atualizados por período, exclusão de contas com confirmação, criação de contas, edição de movimentações, botão Voltar e comprovantes vinculados às movimentações.

## Executar localmente

`npm install`

`npm run dev`

O workflow em `.github/workflows/deploy.yml` publica automaticamente na branch `main` pelo GitHub Pages.
